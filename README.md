# GYANMASTI.AI

GYANMASTI.AI is an advanced AI platform designed and developed by Geetansh Shukla. Built on top of Streamlit and powered by Google Gemini generative models, it offers a visually premium UI/UX, fast interactions, and embedded identity guardrails.

## Setup Instructions

1. **Navigate to the project directory**:
   ```bash
   cd C:\Users\DELL\.gemini\antigravity\scratch\gyanmasti-ai
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Streamlit application**:
   ```bash
   streamlit run app.py
   ```

4. **API Configuration**:
   Open the sidebar in the browser application, expand the **API Key Configuration** section, and input your Gemini API Key.
